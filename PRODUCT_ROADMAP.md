# Product roadmap

## V0.1 — Included
- Storage scanner
- Treemap
- Large files
- Old downloads
- App inventory
- Safe cleanup candidates
- Assisted uninstall
- Local-only privacy
- Spanish / English

## V0.2 — Done
- Configurable large-file threshold wired into scanner
- Hidden files / Library included, packages measured as single items
- Better app last-used metadata (Spotlight `kMDItemLastUsedDate`)
- Quick Look panel
- Treemap drill-down and squarified layout
- Per-item review of uninstall leftovers
- `.app` bundling script

## V0.3 — Next
- Security-scoped bookmarks for persistent folder access
- APFS clone / hard-link accounting
- Duplicate finder with staged hashing
- Scan cache and incremental rescans
- Exportable scan report

## V0.4 — Production
- Native Xcode app project
- App icon and onboarding
- Full Disk Access explainer
- Signed helper only if required
- Hardened Runtime and notarization
- Crash-safe cleanup journal
- Undo / restore workflow
- Hardware compatibility matrix
